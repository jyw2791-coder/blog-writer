# ✍️ AI 블로그 작성기

사진과 기본 정보를 입력하면 **네이버 스타일 블로그 포스팅**을 자동으로 생성해주는 앱입니다.

---

## 🚀 새 PC에 설치하는 방법 (처음 설치 시)

### 1단계 — Python 설치 (없는 경우만)
👉 https://www.python.org/downloads/ 에서 Python 다운로드

> ⚠️ 설치 시 **"Add Python to PATH"** 반드시 체크!

### 2단계 — 앱 폴더 복사
`blog-writer` 폴더를 원하는 위치에 복사  
(예: `C:\Users\사용자이름\Desktop\blog-writer`)

### 3단계 — 설치 및 실행
`설치하기.cmd` 파일을 **더블클릭**

- 최초 실행 시 자동으로 패키지 설치 (1~3분 소요)
- 이후부터는 바로 앱 실행

브라우저에서 **http://localhost:8501** 접속

---

## 📦 이미 설치된 PC에서 실행

`run.cmd` 더블클릭 → 브라우저 자동 열림

---

## 🔑 Gemini API 키 설정 (선택)

API 키 없이도 데모 모드로 동작합니다.  
실제 AI 생성을 원하면 아래에서 무료 발급:

👉 https://aistudio.google.com/app/apikey

발급 후 앱 왼쪽 사이드바 **"Gemini API 키"** 입력란에 붙여넣기

| 무료 한도 | |
|---|---|
| 분당 요청 | 15회 |
| 하루 요청 | 1,500회 |

## 📋 주요 기능

| 기능 | 설명 |
|------|------|
| 🍽️ 맛집 블로그 | 가게 정보 + 사진 → 네이버 맛집 후기 |
| ✈️ 여행 블로그 | 여행지 정보 + 사진 → 감성 여행기 |
| 📦 제품 리뷰 | 제품 정보 + 사진 → 솔직한 리뷰 |
| 🌙 데일리 문 스타일 | bling2min 블로거 문체로 작성 |
| 📷 다중 사진 | 최대 10장 업로드 + AI 분석 |
| 📏 글자 수 설정 | 500자 ~ 2000자+ 선택 |
| 🌐 HTML 저장 | 사진 포함 → 네이버 블로그 붙여넣기 |
| 📋 작성 기록 | 생성한 블로그 오른쪽 패널에 자동 저장 |

## 📁 폴더 구조

```
blog-writer/
├── app.py             ← 메인 앱
├── requirements.txt   ← 필요 패키지 목록
├── 설치하기.cmd        ← 처음 설치할 때 실행
├── run.cmd            ← 이후 실행할 때 사용
├── .env.example       ← API 키 파일 예시
└── blog_history.json  ← 작성 기록 (자동 생성)
```
